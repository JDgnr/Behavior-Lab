# BehaviorLab

A behavioral data science application for tracking
and analyzing personal behavioral patterns.

## Features

- Mood, sleep, stress and exercise tracking
- Persistent CSV storage
- Check-in history
- Descriptive statistics
- Time series visualization
- Pearson correlation analysis

## Tech Stack

- Python
- Streamlit
- pandas
- Git & GitHub

## Installation

pip install -r requirements.txt

## Run

python -m streamlit run app.py

## Privacy

Personal check-in data is stored locally
and excluded from version control.
